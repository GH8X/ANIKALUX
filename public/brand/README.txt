AL-ANIQA LUX — OFFICIAL LOGO

Drop the official logo file into this folder using one of these exact names:

  /brand/logo.png      (preferred)
  /brand/logo.svg
  /brand/logo.webp
  /brand/logo.jpg
  /brand/logo.jpeg

The website detects the first file that exists and displays it in the header,
footer, hero, About page and sign-in screen using `object-contain`, so the
logo's proportions, colours and artwork are never modified, stretched,
cropped or recoloured.

You can also upload the logo at runtime from the dashboard:
  Admin → Brand → "Official logo" → Upload logo

If no file is present, the site shows a neutral placeholder frame with a short
prompt instead of inventing a replacement mark.
